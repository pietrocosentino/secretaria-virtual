# Exclusão de dados — Secretária Virtual

Última atualização: 12 de outubro de 2026.

Para solicitar a exclusão dos dados de atendimento da Secretária Virtual, produto da SmartTec:

1. Envie um e-mail para **pietrocosentino88@gmail.com**.
2. Use o assunto **Exclusão de dados — Secretária Virtual**.
3. Informe seu número de WhatsApp com código do país e DDD e diga que deseja excluir os dados de atendimento associados a esse número.

Não envie senhas, códigos de autenticação, dados de cartão ou documentos de identidade. Se for necessário confirmar a titularidade do número, o responsável pelo atendimento explicará como fazer isso com o mínimo de informações.

A exclusão é realizada manualmente. Ela abrange o registro de atendimento associado ao número no sistema da SmartTec, incluindo estado da conversa, solicitações registradas e respostas armazenadas. Você receberá uma confirmação após o tratamento do pedido, ou uma explicação caso alguma informação precise ser mantida por obrigação legal.

Esse procedimento não apaga mensagens no seu aparelho nem dados mantidos pela Meta. Cópias de segurança dos fornecedores seguem os processos próprios desses serviços; não há garantia de remoção instantânea dessas cópias.

Consulte também a [Política de Privacidade](politica-de-privacidade.md).
